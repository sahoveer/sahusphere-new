## 2025-02-28 - Component Accessibility Patterns\n**Learning:** Found multiple common patterns of missing accessibility in the ImageToPDF component: icon-only buttons missing `aria-label`, custom toggles missing `role="switch"` and `aria-checked`, and expandable settings panels lacking `aria-expanded` and `aria-controls`.\n**Action:** When auditing React components, systematically ensure that all functional icon buttons include `aria-label`, interactive custom toggle buttons act like switches with `role="switch"` and `aria-checked`, and all expandable/accordion UI patterns implement `aria-expanded` tied via `aria-controls` to the matching target `id`.
